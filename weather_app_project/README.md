# 🌦️ Weather App

A simple and responsive Weather App built using **HTML, CSS, Bootstrap, and JavaScript**.
This app allows users to search for any city and get real-time weather details using an API.

---

## 🚀 Features

* 🔍 Search weather by city name
* 🌡️ Displays temperature in Celsius
* ☁️ Shows weather condition (Cloudy, Clear, Rain, etc.)
* 🎨 Beautiful UI with glassmorphism effect
* 📱 Fully responsive design using Bootstrap

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* JavaScript (ES6)
* OpenWeatherMap API

---

## ⚙️ How It Works

1. User enters a city name
2. App sends request to OpenWeatherMap API
3. API returns weather data
4. Data is displayed on screen

---


## ▶️ How to Run

1. Download or clone the project
2. Open `index.html` in browser
3. Enter city name
4. Click **Search**
5. View weather details
