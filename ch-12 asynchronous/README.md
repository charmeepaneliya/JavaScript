
Asynchronous in JavaScript:
======================================

Asynchronous means code does not wait for a task to finish.
It keeps running the next lines while the task happens in the background.

------------------------------------------------------------------------------------------------------

💡 Example 1: Downloading a File 📥

You download a movie or app

While downloading, you use phone for chatting or browsing

👉 Download runs in background → Asynchronous

------------------------------------------------------------------------------------------------------

💡 Example 2: Online Order 📦

You order something from Amazon

You don’t wait at door

You continue your daily work

👉 Delivery happens later → Asynchronous

-------------------------------------------------------------------------------------------------

🧠 In JavaScript:

Some tasks take time, like:

Loading data from internet

Reading files

Waiting with timer

Instead of stopping everything, JavaScript runs them in background

----------------------------------------------------------------------------

📌 Callback Function (Definition)
=================================

Callback is a function that is passed as an argument to another function and is executed later.

👉 Simple words:
A function that runs after another function finishes

------------------------------------------------------------------------------------

📌 setTimeout Function (Definition)
================================

setTimeout is a JavaScript function that runs code after a specified time (delay).

👉 Simple words:
It waits for some time, then runs the function

---------------------------------------------------------------------------------------

Callback = Function called later

setTimeout = Run code after delay
